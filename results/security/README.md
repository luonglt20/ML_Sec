# Security evaluation results

`summary.json` and `summary.csv` are generated by
`scripts/run_security_eval.py summarize` and may be committed for the final
report. Raw per-question predictions, retrieval snapshots, model logs, RAG
indexes and checkpoints are intentionally ignored because they can be large or
contain sensitive provider output.

Do not edit a summary after inspecting results. Re-run the locked scenario and
retain the original raw JSONL locally so every reported aggregate is auditable.
